# ScamSense Product Overview

## User Journey
1. User opens ScamSense.
2. Chooses text, URL, or screenshot for analysis.
3. Submits the content for evaluation.
4. Receives results based on risk assessment.
5. Understands the evidence and recommendations for action.

## MVP Scope
The MVP will include:
- Guest access to scam checks.
- Text and URL analysis.
- Structured evidence results.
- Basic scoring functionality.
- User-friendly interface for assessments.
