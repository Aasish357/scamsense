# ScamSense browser extension

A Manifest V3 extension that checks whatever you are looking at with ScamSense:
a selection, a link, or the page itself. The toolbar icon is badged with the
risk score so you get a signal without leaving the page.

## Install (local development)

```bash
# 1. Start the backend (the extension talks to it directly)
cd apps/web
python -m uvicorn apps.web.src.app.main:app --port 8000

# 2. Load the extension
#    Chrome: chrome://extensions -> Developer mode -> Load unpacked -> apps/extension
#    Edge:   edge://extensions   -> Developer mode -> Load unpacked -> apps/extension
```

No build step: the extension is plain HTML/CSS/JS. The icons are generated by
`scripts/generate_icons.py` at the repository root.

## Use it

- Select text -> right-click -> **Check selection with ScamSense**.
- Right-click a link -> **Check this link with ScamSense**.
- Right-click a page -> **Check this page with ScamSense**.
- Click the toolbar icon to see the last verdict, or check the current tab.
- **Open in ScamSense** hands the content to the web app for the full analysis.

## Pointing it at a deployed backend

The extension ships with permission for a local backend only
(`http://127.0.0.1:8000`). Open the popup's settings, enter your API and web app
URLs, save, and grant the extension access to that host when Chrome asks. The
verdict is rendered in the popup; the full assessment always happens in the web
app, so the extension stays a thin, permission-light front door.

## Tests

```bash
cd apps/web
node tests/e2e/extension_check.js   # requires the backend on :8000
```

The test loads the real extension into Chromium, drives the service worker
through the popup, and asserts the score, the badge, the rendered evidence and
the unreachable-API error path.
